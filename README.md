# 講了算（手機版）

手機網頁版的語音輸入：按住講、放開出字，整理好的繁體中文自動複製，到 LINE 長按貼上。
電腦版在 `400_Projects/voice-input/`，兩邊的整理規則一樣。

## 用法

- **按住講**：按住藍色麥克風講話，放開就出字。
- **長講**：點一下麥克風開始，雙手放開慢慢講，講完再點一下。不要了按「取消這段」。
- 出字後會自動複製；也可以先在框裡改字再按「複製」，或按「傳到 LINE…」直接分享。
- 第一次打開會請你貼 Groq 免費金鑰（console.groq.com/keys），只存在這支手機的瀏覽器裡。
- 設定裡的「我的詞庫」可以加小組成員名字，只存在這支手機（公開網頁上的預設詞庫只有聖經與教會用語）。

## 加到主畫面

- Android（Chrome）：右上角 ⋮ →「加到主畫面」。
- iPhone（Safari）：下方分享鈕 →「加入主畫面」。

## 檔案

| 檔案 | 用途 |
|------|------|
| index.html | 畫面、錄音、按鈕、紀錄、設定 |
| engine.js | 辨識＋整理的大腦（Groq Whisper → Groq 中文模型 → 規則保險） |
| manifest.json、icon-*.png | 加到主畫面用的名稱與圖示 |
| tests/engine_test.mjs | `node tests/engine_test.mjs`；設 `GROQ_API_KEY` 測雲端、`OPENCC_UMD` 指向 opencc-js 的 full.js 測簡轉繁 |

## 隱私

聲音會送到 Groq 辨識和整理；金鑰、詞庫、紀錄都只存在手機瀏覽器。代禱、輔導等隱私內容請用電腦版的「只用本機」模式。
